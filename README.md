### Sobre este desafio
Neste desafio o objetivo é criar um encurtador de URLs completo utilizando os conceitos de Spec-Driven Development

#### O que foi implementado
- .NET 10, C#, Minimal API
- Persistência em SQLite via EF Core
- Testes com xUnit

Neste processo eu aprendi:
* Usar a IA (Copilot) para revisar os artefatos do SDD.
* Usar a IA (Copilot) para gerar o código e os testes da aplicação.
